# 주식 모델용 API 발급 순서

작성 2026-10-27. 사이트 화면과 메뉴 이름은 바뀔 수 있습니다. 블로그·제3자 자료로 확인한 부분은 "확인 필요"로 표시했습니다.

## 한눈에 보기

| 순서 | 사이트 | 받는 것 | 비용 | 승인 대기 |
|---|---|---|---|---|
| 1 | KRX Open API (openapi.krx.co.kr) | 인증키 + 서비스별 활용 승인, KRX 계정 ID/PW | 무료 | 있음 (관리자 승인 2번) |
| 2 | 한국투자증권 계좌 + 상시 모의투자 | 실전 계좌, 모의 계좌 | 무료 | 계좌 개설에 시간이 걸릴 수 있음 |
| 3 | KIS Developers (apiportal.koreainvestment.com) | 실전 APP KEY/SECRET, 모의 APP KEY/SECRET | 무료 | 즉시 |
| 4 | OpenDART (opendart.fss.or.kr) | 인증키 | 무료 | 이메일 인증 후 |
| 5 | 공공데이터포털 (data.go.kr) | 일반 인증키 | 무료 | 보통 자동 승인, 키 동기화에 시간이 걸릴 수 있음 |
| 6 | 텔레그램 BotFather | 주식 전용 봇 토큰, chat_id | 무료 | 즉시 |
| 선택 | 유료 데이터 (FnGuide, 퀀티와이즈 등) | 상폐 포함 과거 데이터 | 유료, 가격 미확인 | 상폐 종목 테스트 후 결정 |

키 없이 쓰는 것: FinanceDataReader(상장폐지 종목 목록), KIND(kind.krx.co.kr, 시장조치·상장폐지 조회).

승인 대기가 있는 KRX를 가장 먼저 신청하고, 기다리는 동안 나머지를 처리합니다.

## 1. KRX Open API + KRX 계정

용도: 거래소 공식 일별 시세·종목 정보, 그리고 pykrx 로그인용 계정.

1. openapi.krx.co.kr 접속
2. KRX Data Marketplace 회원가입 (개인은 본인인증 또는 소셜 로그인)
3. 로그인 → 마이페이지 → **API 인증키 신청** → 관리자 승인 대기
4. 승인되면 **서비스 목록**에서 필요한 API마다 **활용신청** → 다시 관리자 승인 대기
   - 주식: 유가증권(코스피) 일별매매정보, 코스닥 일별매매정보, 유가증권 종목기본정보, 코스닥 종목기본정보
   - 지수: KOSPI 시리즈 일별시세, KOSDAQ 시리즈 일별시세 (코스피200 기준선용)
   - 정확한 API 이름은 서비스 목록 화면에서 확인
5. 마이페이지 → **API 인증키 발급내역**에서 키 확인, **이용현황**에서 호출량 확인

주의
- 활용신청을 안 한 서비스를 부르면 "Unauthorized API Call" 오류가 납니다.
- 호출 한도는 제3자 문서에 10,000건으로 나와 있지만 공식 확인은 못 했습니다.
- 가입한 ID/PW는 pykrx 로그인에도 씁니다. 최신 pykrx는 로그인이 없으면 일부 함수가 오류 없이 빈 결과를 돌려줍니다.

## 2. 한국투자증권 계좌 + 상시 모의투자

1. 한국투자증권 앱으로 **본인 명의** 계좌 비대면 개설 (가족 명의 불가)
2. 한국투자증권 홈페이지 또는 앱에서 **상시 모의투자** 참가 신청 → 모의 계좌번호 받기
3. 계좌번호를 적어 둡니다. 형식은 8자리 + 상품코드 2자리(보통 01)입니다.

## 3. KIS Developers 앱키

1. apiportal.koreainvestment.com 접속 → 회원가입 → 로그인
2. 상단 **API 신청** 또는 **인증키 발급** 메뉴
3. 본인 인증 (공동인증서, 모바일 OTP, 휴대폰 인증 중 화면 안내대로)
4. 앱 등록: 앱 이름, 설명, 거래 환경 선택
5. **실전투자**용 한 번, **모의투자**용 한 번, 따로 발급
6. 표시된 **APP KEY**와 **APP SECRET**을 그 자리에서 바로 저장

주의
- APP SECRET은 발급 직후에만 평문으로 보입니다. 놓치면 앱을 지우고 다시 발급해야 합니다.
- 접근 토큰은 24시간 유효합니다. 매 호출마다 새로 받으면 차단되니, 하루 한 번 받아 저장해 두고 씁니다.
- 실전과 모의는 서버 주소, 키, 토큰, 일부 tr_id가 모두 다릅니다.
- 실전 키는 조회 전용으로만 씁니다. 주문 코드는 모의 단계가 끝날 때까지 붙이지 않습니다.
- 넥스트레이드: 공식 예제의 시장 코드는 J(KRX), NX(NXT), UN(통합)입니다.
- 앱키 자체의 유효기간은 확인하지 못했습니다. 포털에서 만료일이 표시되는지 확인하세요.

## 4. OpenDART

1. opendart.fss.or.kr 접속
2. **인증키 신청/관리** → **인증키 신청**
3. 이메일, 사용 용도 입력, 약관 동의
4. 메일로 온 인증 링크 클릭
5. **인증키 신청/관리** → **오픈API 이용현황**(또는 비슷한 메뉴)에서 40자리 키 확인

주의
- 일일 요청 한도는 20,000건으로 알고 있지만, 공식 사이트가 접속되지 않아 다시 확인하지 못했습니다.
- 분당 100회 이상 요청하면 제한될 수 있다는 안내가 있습니다(제3자 자료).
- 공시 접수 시각 필드가 응답에 있는지 첫 호출 때 확인하세요. 없으면 서버가 몇 분마다 조회해 처음 본 시각을 직접 기록해야 합니다.

## 5. 공공데이터포털 (백업·대조용)

1. data.go.kr 회원가입 → 로그인
2. "금융위원회_주식시세정보" 검색 → **활용신청**
3. 마이페이지 → **개발계정**에서 일반 인증키 확인 (Encoding 키와 Decoding 키 두 가지가 나옵니다)

주의
- 하루 1회, 기준일 다음 영업일 13시 이후 갱신됩니다.
- 개발계정 한도는 하루 10,000건입니다.
- 신청 직후에는 키가 바로 안 먹을 수 있습니다. 조금 기다렸다가 다시 시도하세요.

## 6. 텔레그램 주식 전용 봇

1. 텔레그램에서 @BotFather → `/newbot` → 이름 입력 → 봇 토큰 받기
2. 만든 봇에게 아무 메시지나 보낸 뒤, 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 열어 chat_id 확인
3. 코인 알림과 섞이지 않게 봇이나 채팅방을 따로 둡니다.

## 키 보관 (.env 예시)

서버 환경변수나 .env 파일에 두고, 코드와 git에는 절대 넣지 않습니다. .env는 .gitignore에 추가합니다.

```
# 한국투자증권 실전 (조회 전용)
KIS_APP_KEY=
KIS_APP_SECRET=
KIS_ACCOUNT=          # 8자리
KIS_ACCOUNT_PROD=01   # 뒤 2자리, 문자열로

# 한국투자증권 모의
KIS_PAPER_APP_KEY=
KIS_PAPER_APP_SECRET=
KIS_PAPER_ACCOUNT=

# KRX
KRX_OPENAPI_KEY=
KRX_ID=               # pykrx 로그인용
KRX_PW=

# 공시
DART_API_KEY=

# 공공데이터포털
DATA_GO_KR_KEY=       # Decoding 키

# 텔레그램
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

계좌번호 뒤 2자리를 숫자로 읽으면 앞의 0이 사라집니다. 문자열로 다루세요.

# 주식 "오를 종목 / 내릴 종목" 모델: 토론 결과와 최종 설계

## 1. 결론

**"내일 어떤 종목이 오를까"를 맞히는 모델은 만들지 않는다.** 두 에이전트가 이 점에 합의했다. 코인에서 급등 추격이 모두 손실이었던 이유(조작성 급등, 사람의 느린 반응, 비용)가 주식에서도 그대로 재현된다는 근거가 많다.

**대신 세 층으로 만든다.**
1. **회피 엔진**: 사면 안 되는 종목을 거른다. 알파(초과수익)가 없어도 바로 가치가 있다.
2. **위험 관리**: 변동성으로 비중을 정하고 손실 한도를 건다. 수익률보다 변동성이 훨씬 예측 가능하다.
3. **순위 모델**: 느린 팩터로 종목 순위를 매긴다. 엄격한 통과 기준을 넘기 전까지 모의로만 돌린다.

**돈의 배치**: 자금의 80~90%는 저비용 시총가중 지수 ETF(한국·미국). 개별주는 10~20% 이하. 순위 모델에 실제 돈은 통과 기준을 넘은 뒤에만.

**기대치**: 이 시스템의 가치는 초과수익이 아니라 손실 회피와 규율이다.

## 2. 토론 요약

### 합의된 것
| 쟁점 | 합의 |
|---|---|
| 개별 종목 단기 방향 예측 | 쓸모없다. 최고 수준 학술 모델도 월간 R² 0.4%(예측-실제 상관 약 0.06), 그것도 롱숏·비용 전·월 회전율 110~130% 조건 |
| 경주마(급등 추격) | 매수 신호로 절대 쓰지 않는다. 매수 거부권과 음(-) 특징으로만. 미국·한국 모두 "상승률 순위 노출·복권형 종목은 이후 저조" 연구가 있다 |
| 개인의 우위가 있는 곳 | "사지 않기"는 공매도 장벽 밖에 있다. 희석(유상증자·CB)·부실·테마·복권형 종목 회피가 가장 튼튼하다 |
| 뉴스·LLM | 뉴스는 밀리초 안에 반영된다. LLM은 예언자가 아니라 공시 분류기로만 쓴다. 학습 컷오프 이전 기간 백테스트는 믿지 않는다 |
| 모델 종류 | 단순 선형 합성 점수가 기본. GBM은 선형을 통계적으로 이길 때만 |
| 미국 | 종목선택 모델은 빼고 지수 ETF로만. 국내 증권사 경유 왕복 0.5%+, 환전, 양도세 22%가 개인에게 비대칭으로 불리 |
| 한국 모멘텀 | 쓰지 않는다. 한국 개별주는 모멘텀보다 단기 반전이 우세 |

### 회의론자가 이긴 쟁점
- **기준선**: 찬성 측은 "유니버스 동일가중"을 이기면 채택하려 했다. 하지만 2025년 코스피는 약 75.6% 올랐고 시총 증가분의 49%를 삼성전자·SK하이닉스 두 종목이 만들었다(헤럴드경제). 2026년 5월에는 두 종목이 코스피200의 50%를 넘었다. 이런 시장에서 분산 포트폴리오는 동일가중을 이겨도 사용자의 실제 대안인 코스피200 ETF에 크게 질 수 있다.
- **검증의 검정력**: 실력이 0인 모델도 원 설계의 관문을 꽤 높은 확률로 통과한다(회의론자 정규근사 계산, 추적오차 10% 가정: Sharpe ≥ 0.3 기준 약 17%, 잠금 상자 기준 약 76%, 모의 6개월 IC > 0 기준 약 50%). 10년 데이터로 t=2를 넘으려면 IR이 약 0.63 이상이어야 한다. 진행자가 계산을 확인했다(표준오차 1/√10 ≈ 0.32).
- **레이블과 보유기간 불일치**: 레이블은 20거래일인데 회전율 상한 때문에 실제 보유는 약 3개월. 단기 반전·MAX·수급 효과는 1개월 안에 사라진다.
- **회피 모델의 누수**: 60·120일 레이블에 20일 퍼지만 두면 학습 데이터가 검증 구간의 미래를 본다.
- **데이터 현실**: OpenDART 재무 API는 2015년부터. 2023년 이전 수급은 개인 CFD 자금이 외국인·기관으로 잘못 집계돼 있었다. 상폐 종목 시세를 무료로 얻을 수 있는지는 확인되지 않았다.

### 찬성 측이 지킨 쟁점
- **비용 산수**: "매주 왕복하면 연 13%"는 포트폴리오를 매주 통째로 바꿀 때 이야기다. 월 회전율 30% 이하로 묶으면 연 비용은 약 1.9%(찬성 측 계산).
- **HFT 경쟁**: 월 1회, 다음날 시가 거래는 밀리초 게임이 아니다.
- **회피는 장벽 밖**: 발행(희석) 효과는 41개국에서 "발행 후 저조" 쪽에서 나왔다. 이것은 사지 않는 것만으로 얻을 수 있다.
- **찬성 측이 스스로 고친 것**: 지수 쏠림을 놓쳤다고 인정하고 코어-위성 구조, 월 1회 리밸런싱, 미국 종목선택 제외, ±20% 파라미터 견고성, VI 미체결 처리를 추가했다.

### 진행자 판정 (남은 쟁점)
1. **최종 기준선은 시총가중 지수(코스피200)**. 유니버스 동일가중은 진단용 보조 지표로만.
2. **레이블을 보유기간에 맞춘다**: 순위 모델 레이블은 T+1 시가 → T+61 시가(약 3개월) 초과수익 순위. 단기 관심 특징(경주마류)은 순위 모델이 아니라 거부권에만 쓴다.
3. **퍼지는 가장 긴 레이블에 맞춘다**: 회피 모델 120거래일 레이블이면 퍼지 120거래일.
4. **회피 모델은 단순 규칙을 이겨야 존재한다**: 단순 IVOL(고유변동성)·MAX 필터를 연 0.5%p 이상 이기지 못하면 분류기 대신 규칙만 쓴다.
5. **거부권과 이벤트 충돌**: 실적·공급계약 공시로 오른 종목까지 거부권이 막는 문제. "재료 없는 급등"만 거부하고, "재료 있는 급등"은 진입을 N일 보류한 뒤 재평가한다. 이 둘을 가르는 것이 사용자가 처음 말한 "경주마 vs 진짜 상승" 구분이며, 사건 300건 이상으로 따로 검증한다.
6. **실제 돈 투입 관문은 회의론자의 숫자를 채택한다**(4장).
7. **가장 가능성 높은 결말은 "지수 ETF + 회피 체크리스트"**이며, 이것은 실패가 아니라 정상 종료 경로다.

## 3. 최종 설계

```
[수집]  KRX+NXT 시세(거래소×세션 분리 저장) · 투자자별 매매 · DART 공시(접수 시각) · 공매도 잔고 · 시장경보
   │    신선도 점검 실패 → 그날 신호 없음
   ▼
[1층 회피 엔진]  ← 바로 운영. 보유 종목 전체에도 매일 적용
   ├ 하드 필터: 관리종목, 투자주의환기, 감사의견 비적정, 투자경고·위험, 거래정지, 스팩, 상장 60일 미만, 코스닥 상폐 요건 근접
   ├ 희석: 유상증자(유형·희석률), CB·BW 발행·전환가 리픽싱·전환청구 추가상장
   ├ 경주마 거부권: 재료 없는 급등, 상승률 상위 반복 노출, 상한가, 거래량 5배+, MAX 상위, 테마 뉴스 군집,
   │               프리·애프터 소량 체결 이상치 → 20거래일 매수 금지, 보유 시 경고
   └ 내부자·대주주 매도 사전공시(2024-07 도입, 30일 전 공시)
   ▼
[2층 위험 관리]  변동성 역가중 비중, 종목당 ≤5%, 업종당 ≤25%, 계좌 손실 한도
   ▼
[3층 순위 모델]  ← 모의 전용, 관문 통과 전까지 실제 돈 없음
   ├ 유니버스: 거래대금(KRX+NXT 합산) 상위, 시총 하위 20% 제외
   ├ 특징: 가치(B/M, E/P), 수익성(총이익률), 저변동성, 순발행 낮음, 1개월 반전, 부실 위험
   ├ 레이블: T+1 시가 → T+61 시가 코스피 대비 초과수익 순위
   ├ 모델: 선형 합성 점수(기본) vs LightGBM(도전자)
   └ 포트폴리오: 롱 온리 20~30종목, 월 1회, 진입 상위 10% / 이탈 상위 30% 밖, 월 회전율 ≤30%
   ▼
[알림]  텔레그램: 보유 종목 위험 경고, 매수 후보의 체크리스트 결과, 월간 모델 성적표
```

### 기대 성과 (찬성 측 주관적 추정, 비용·세후)
| 비교 | 연 초과수익 | 확신도 |
|---|---|---|
| 회피 목록 효과(유니버스 동일가중 대비) | +0.5~1.5%p | 중간 |
| 모델 포트폴리오(유니버스 대비) | 0~+2%p | 낮음 |
| 전체 계좌(코스피200 대비) | 0~+0.6%p | 낮음 |

의도대로 작동해도 5년 뒤 약 3분의 1 확률로 기준선에 뒤질 수 있고, 어느 한 해는 지수와 ±10~20%p 벌어질 수 있다.

## 4. 실제 돈 투입 관문 (회의론자 기준 채택)

모두 통과하면 자금의 10~20%까지 순위 모델에 투입.

- **데이터 감사**: 상폐 종목 시세 99% 이상 확보, 정정 전 원본 기준 재무 95% 이상
- **순성과(실제 포트폴리오, 비용·세후)**: 유니버스 동일가중 대비 연 +3%p 이상, IR 0.6 이상, t 2 이상
- **비용 2배**: 그래도 연 +1.5%p 이상
- **시총가중 지수 대비**: 순초과 0 이상
- **과최적화 점검**: Deflated Sharpe 0.95 이상, 과적합 확률(PBO) 0.25 이하, 레이블을 섞은 가짜 실험 대비 상위 5%
- **회피 모델**: 단순 IVOL 필터를 연 0.5%p 이상 이김
- **경주마 거부권**: 사건 300건 이상, 거부된 종목의 이후 20일 초과수익 −1% 이하, t −3 이하
- **잠금 상자(2024-01~2026-06)**: IR > 0. 이 구간은 대형 반도체 랠리와 공매도 금지기가 겹치므로 레짐별로 쪼개서도 본다
- **모의 12개월**: 실제 체결가와 모의 체결가 괴리 편도 0.15% 이하

## 5. 코인 경주마 시스템에서 가져올 것

| 그대로 씀 | 용도 바꿈 | 버림 |
|---|---|---|
| 수집기 → 신호 → 백테스트 → 모의 장부 → 텔레그램 파이프라인 | 경주마 탐지기 → 매수 거부권·회피 엔진 | 3분·30분 추격 규칙 |
| 레드팀에서 고친 것: 단일 비용 함수, 안 산 신호까지 전부 기록, 피드 끊김 감시, 상폐 자산 보존 | 진입 지연 민감도 분석 → 모든 백테스트의 표준 보고 항목 | 실시간 진입 로직 |
| 유형별 성적표, 손익분기 승률 대비 자동 중단 | 거래소 공지 파서 → DART 공시 접수 시각 기록 | 프리·애프터 가격 기반 매수 신호 |
| | 텔레그램 매수 알림 → 보유 종목 위험 알림 | |

## 6. 만드는 순서

0. **데이터 감사부터.** 상폐 종목 과거 시세 확보 가능 여부, DART 접수 시각, KRX 투자자별 자료에 NXT가 합산되는지 확인. 여기서 막히면 3층은 시작하지 않는다.
1. **회피 엔진 + 보유 종목 위험 알림.** 알파 검증 없이 바로 쓸 수 있다.
2. **경주마 거부권 효과 검증.** 재료 없는 급등과 재료 있는 급등을 나눠서, 각각 사건 300건 이상.
3. **순위 모델 백테스트.** 2015~2023 워크포워드(퍼지 = 레이블 길이), 2023-09 CFD 분류 변경 전후와 공매도 금지·재개·NXT 레짐별 분리.
4. **잠금 상자 한 번 열기 → 모의 12개월.**
5. **관문 통과 시 10%부터.**

## 7. 확인하지 못한 것

- KRX 투자자별 매매 자료에 NXT 거래가 합산되는지
- 투자자 분류가 바뀐 정확한 날짜(CFD 개편 시행일 2023-09-01과 같은지)
- 상폐 종목 과거 시세를 무료로 확보할 수 있는지(가장 큰 데이터 위험)
- 2026년 증권거래세율(블로그 수준으로만 확인, 코스피·코스닥 0.20%로 보도)
- 한국 학술 연구가 없는 효과: 상한가 다음날, 투자경고 지정 후, 공매도 재개 이후 잔고 상위 종목, CB 리픽싱 후 성과
- 2025년 "코스피를 이긴 종목 12.9%"(회의론자 인용, 진행자 검색으로는 확인 못함)
- 기대 성과 표와 비용 계산은 에이전트의 추정·계산이며 실측이 아니다

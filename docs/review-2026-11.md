# 건우주식 보드 내부 점검 (2026-11-10)

주인 요청: "각 영역별 담당자 및 반대자 만들고 서로 회의 및 분석 하고 총괄팀장이 최종 정리해. 다른 곳들 자료나 주소 가서 필요한 것들 도입하는 것도 해."

## 1. 어떻게 했나

| 영역 | 담당자(잘된 점·더할 것) | 반대자(레드팀) |
|---|---|---|
| A 데이터·운영 | 수집·재시도·백업·배포·감시 | 메모리·놓친 날·조용한 실패를 실제 규모 가짜 데이터로 재현 |
| B 분석·투자 판단 | 회피 엔진·점수·예측가·수급·뉴스 + 다른 서비스 비교 | 야후 2년치 50종목으로 예측가·경주마·검증 t값을 실측 |
| C 화면·사용성 | 휴대폰·PC 캡처 측정 + 네이버·토스·kospilab·알파스퀘어·Finviz 비교 | "더하기 전에 빼라" — 매수 신호처럼 읽히는 곳 |
| D 보안·안정성 | 배포 층·키·쿠키·갭 봇과의 격리 | 샘플 보드·격리 인스턴스만 공격(운영 주소는 헤더 확인 GET 1회) |

1. 8명이 따로 1차 보고서를 냈다(발견마다 근거·재현·심각도).
2. 같은 영역의 담당자↔반대자가 서로의 보고서를 읽고 반박했다(교차 회의).
3. 총괄팀장이 합의·쟁점을 정리해 결정하고 구현했다. 구현 중에 레드팀이 고친 코드를 다시 공격해 남은 구멍 4개를 더 찾았고, 그것도 막았다.

**결론**: 지표는 '지금 값이 1년 중 어디쯤인지 + 무슨 뜻인지'까지만. 근거: 거시 변수의 수익률 예측력은 표본 밖에서 실패(Goyal·Welch), 야후 2016~2025 주간 실측에서 원/달러 변화의 다음 주·달 코스피 예측력 ≈ 0, VIX 30 이상 뒤 21일 코스피 평균 +4.8%(흔들림은 예고하지만 방향은 반대).

**1차 (반영)**: 한국은행 ECOS 수집(기준금리·국고채 3/10년·원/달러·엔·위안 매매기준율·소비자물가, 1년치, 일일 수집 끝·아침), 야후 지표용 목록 분리(미국채 10년·VIX·달러인덱스 — 기호마다 따로 실패, 예측가용 목록도 하나 막혀도 나머지 받음), 📚 지식 > 📊 지표 탭(1개월 변화·1년 중 위치·회색 추세선·기준일·지연/튐 표시), 홈 '시장 한눈에' 2열 6칸(칸마다 기준일), 금통위·FOMC(손 입력, 비면 운영 경고)·옵션만기(규칙 계산) 일정, API 화면 ECOS 키 칸.

**2차**: 미국채 2년·장단기 금리차·미국 물가(FRED 키 결정 후), VKOSPI(KRX 활용신청), 예탁금·신용잔고(KIS 승인 확인), 수출, 주담대 금리(부동산 탭).

**하지 않기로**: 시장 흔들림 온도계(→ 6~12개월 기록만 쌓고 재검토), 보유 종목 환율 민감도 β(사실상 시장 β, 매매 단서), 거시 기반 신호·경기 국면·종합 점수·발표일 경고·실시간 갱신·전체 경제 캘린더.

## 말투

- 존댓말, 담담, 단정하지 않음. 화자는 "기발해" 또는 3인칭 "도형 선생은 이렇게 봅니다".
- 서비스 이름보다 **고민 단어**(손없는날 · 침대 머리 방향 · 작명소)로 말한다. 제목도 고민 단어.
- 고유 용어(백호살·복단일·모창)는 첫 등장에 "백호살이라는 날" 식으로 풀고, 화면 카드·자막에는 한자 없이 한글로.

고객 특정 정보 · 출산택일 · "사무실로 오세요" · 아바타·가상 인물 · 부모님 목소리 변조.

## 블로그 글 구조 (주 1편, 1,500~2,500자, 문단형)

독자 상황 → 통념 → 이유 → 바로 쓸 것 2~3개 → 익명 사례 1 → 홈페이지 링크 → **"전화·카카오톡으로 전국 상담"** 한 줄.
브랜드는 마지막 문단에만. 홍보 구조("저희는 → 연락주세요")는 네이버 저품질 필터에 걸린다.
이미지는 머리말 `images:` 에 장면 지시(도면/달력/해법)로 적으면 graphics.py 가 그린다 — 쇼츠와 같은 그림이라 브랜드가 이어진다.
태그 8개, 제목은 검색어("이사택일" 230 이 아니라 "손없는날" 103,900).

## 쇼츠 대본 구조 (45초 표준형)

| 초 | 화면 | 나레이션 |
|---|---|---|
| 0–2 | 훅 카드(큰 글자 1줄) | 질문 또는 반전. 인사 없음 |
| 3–10 | 도면/달력 — 현재(회색 점선) | 흔한 상황, 공감 |
| 11–25 | 도면/달력 — 이유(화살표) | 왜 그런지 |
| 26–38 | 해법 카드 2~3장(붉은 실선) | **답을 다 준다**(아끼면 이탈) |
| 39–45 | 마무리 카드 + 로고 | "사람마다 다릅니다. 자세한 건 설명란에." |

시리즈: **A 방 보는 법**(도면) · **B 날 보는 법**(달력) · **C 30년 사례**(추상 도면+글) · **D 한 줄 정의**(단어 카드, 15~20초).
나레이션 총 **130~175자(공백 제외, ≈ 40~52초)**. 실측 1초에 3.4자. 190자를 넘기면 60초를 넘어 쇼츠가 아니다. 장면 사이 쉼 0.45초는 기계가 넣는다.
제목 = 검색어 ("침대 머리 방향 서쪽, 괜찮을까요"). 설명 첫 줄 홈페이지 해당 페이지, 둘째 줄 "전화·카카오톡 전국 상담", 셋째 줄 AI 음성 표기.
고정 댓글: 홈페이지 링크 + "이 영상은 도형 선생의 기록을 바탕으로 만들었습니다".
목소리는 `pipeline/voices.json` 의 default 하나로 고정 — 속도·쉼 바꾸지 않는다.

## 시각 정체성

흰 카드 · 붉은 선 #c7000a · 진회색 · Noto Sans KR. 도면은 위에서 본 방(회색 선), 침대는 붉은 사각형, 머리 방향 표시,
창·문·화장실 표시. 좋은 배치 = 붉은 실선, 피할 배치 = 회색 점선. 달력은 손없는날 회색 점, "우리 가족 날" 붉은 원.
배경음악 없음(저작권). 배경 클립은 얼굴 없는 무료 라이선스만, 출처를 적는다.

# 기발해 콘텐츠 기획 v3 — 요약 (공개해도 되는 범위)

2026-11-27 · 상태: **주인 검토 대기** · 실행한 것 없음(조사와 기획만).
전체 문서(홈페이지 점검 결과, 문의 기준선, 판매 채널 검토, 보안 사항 포함)는 주인에게 따로 전달했다.
이 저장소가 공개 상태인 동안에는 그 내용과 재료(답변·전사문)·미리보기 영상을 여기에 올리지 않는다.

만든 순서: 조사 4건 → 초안 → 반대자 3명(시청자·제작, 사업·문의, 운영·위험)의 검토 → 수정.

## 원칙

1. **품질을 막는 것은 도구가 아니라 재료와 틀이다.** 도형 선생의 실제 말·판단에 근거하지 않은 글과 영상은 만들지 않는다. 지어내지 않는다.
2. **콘텐츠보다 먼저**: 문의를 받는 그릇(홈페이지·카카오)을 고치고, 지금 문의가 몇 건인지 기준선을 센다.
3. **재료는 숙제가 아니라 일의 부산물로 모은다**: 상담 직후 1분 메모, 이미 보낸 답변, 방 사진을 보고 하는 한마디. 부모님이 사실을 확인한 '재료 카드'만 콘텐츠가 된다.
4. **영상은 주인의 참고 영상을 과녁으로 시범 1편부터**: 대본 1개 × 화면 2안, 목소리는 이름을 가리고 고른다. 통과 못 하면 멈춘다.
5. **자동화는 '만드는 일' 전부, 공개는 처음 4주 동안 주인 손으로.** 통하면 예약 업로드까지 자동으로 올린다. 거부권 방식·완전 자동은 넣지 않는다.
6. **재료 1건에 1편, 없으면 쉰다.** 많아야 주 3쇼츠·주 1글.

## 영상

- 화면: 화면 가득한 방 그림 + 실물 사진(풍수 나침반·만세력·택일지) 위에 선과 자막. 흰 카드 없음. 움직이는 도면은 삽입 컷으로만. 화면에 'AI 음성' 표기.
- 구조: 결론을 먼저 말한다.

| 형식 | 길이 | 시작 |
|---|---|---|
| 판단 먼저 | 15~25초 | "이삿날은 짐 옮기는 날이 아닙니다" → "첫 밤 자는 날입니다" → 이유 |
| 말린 일 | 25~35초 | 결말이 효과가 아니라 판단인 이야기 |
| 어디부터 볼까요 | 15~20초 | 방 사진에 번호 셋 → 3초 뒤 답 |
| 문답 | 10~15초 | 실제 받은 질문 → 답 → 이유 |

- 검수는 완성본에: 첫 프레임부터 음성과 주제 그림, 말 속도, 무음, 말한 사물의 등장 시점, 음성을 받아써 대본과 대조, 대본의 숫자·장소·결과가 재료 원문에 없으면 실패, 날짜 지정·효과 단정은 실패.
- 상담 안내는 마지막 2초 안. '값과 절차' 영상 1편을 모든 쇼츠의 관련 동영상 링크로 건다.

## 블로그

- 글의 순서는 사려는 사람 순: 비용과 받는 것 → 손없는날을 못 잡았을 때 → 실제 판단과 사례.
- 주 1편 이하, 재료가 있을 때만. 발행은 주인 손으로(네이버 약관).

## 자동화 단계

| 일 | 1단계 (시범 ~ 운영 4주) | 2단계 (통하면) |
|---|---|---|
| 재료 정리·기획·글·대본·영상·검수 | 자동(클라우드 예약 작업, 주 1회) | 자동 |
| 승인 | 주인, 주 1회 | 주인, 주 1회 |
| 유튜브 공개 | 주인 손 | 자동 예약(승인 24시간 뒤, 취소 가능, 승인은 서버에만 기록) |
| 네이버 발행 | 주인 손 | 주인 손 |

2단계 조건: 4주차에 계속하기로 함 + 비공개 저장소 분리 + 영상 작업실을 주식 보드와 다른 프로그램으로 띄움.

## 도구

- 영상: 코드로 그리는 모션 그래픽(Remotion, 3인 이하 무료)을 클라우드 작업 공간에서 제작. 예비는 JSON2Video(기존 코드).
- 목소리: 두 회사 이상의 후보에서 고름. 효과음만 사용. 생성형 AI 영상과 아바타는 쓰지 않는다.
- 비용: 월 1만 원 안팎.

## 판단

- 본 지표: 주간 새 문의·결제가 기준선보다 늘었나.
- 쇼츠 보조 지표: 넘기지 않고 본 비율, 평균 시청 비율(후반 12편 중앙값). 조회수는 품질 증거로 쓰지 않는다.
- 멈춤 조건을 미리 정한다. 문의 수가 적어 우연과 가르기 어려우니 결과는 방향으로 읽는다.
